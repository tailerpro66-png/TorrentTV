TorrentTV — проект приложения для Android TV, предназначенного для поиска фильмов, просмотра информации о них и воспроизведения видео из доступных источников.

🎬 Каталог фильмов

Поиск фильмов и просмотр сведений: названий, постеров, описаний и другой информации.

📺 Для Android TV

Проект ориентирован на просмотр на телевизоре и управление с помощью пульта.

▶️ Воспроизведение

Предусматривается воспроизведение видео из источников, доступных пользователю и разрешённых к использованию.

Информация о данных
Для отображения сведений о фильмах приложение может использовать TMDB API. TorrentTV не является продуктом TMDB и не одобрено TMDB. Названия, изображения и сведения о фильмах принадлежат соответствующим правообладателям.
